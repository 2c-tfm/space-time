# space-time

A space physics simulator written in C. Renders a 2D space fabric that warps under gravity, simulates Newtonian orbital mechanics, and visualises object trails.

## Dependencies

- [raylib](https://github.com/raysan5/raylib) (submodule)
- [cJSON](https://github.com/DaveGamble/cJSON) (submodule)

## Build

```sh
make
make test
```
